Política de Privacidade

Máquina de Shorts · última atualização: 3 de outubro de 2026

1. O que é este aplicativo

A Máquina de Shorts é uma ferramenta pessoal de automação. Ela é operada exclusivamente pelo seu autor, no próprio computador, para publicar vídeos no canal do YouTube do próprio autor. Ela não é oferecida a terceiros e nenhuma outra pessoa faz login nela.

2. Dados do Google acessados

Com a autorização do autor, via OAuth do Google, o aplicativo acessa apenas a conta do YouTube do próprio autor para:

  • enviar vídeos e definir título, descrição, tags e privacidade de cada vídeo;
  • ler informações e estatísticas do canal e dos vídeos (views, curtidas, inscritos e, quando disponível, receita), exibidas num painel local.

3. Armazenamento

Os tokens de acesso e os dados lidos ficam armazenados somente no computador do autor. Não existe servidor externo, banco de dados na nuvem ou cópia desses dados fora dessa máquina.

4. Compartilhamento

Nenhum dado é vendido, compartilhado ou transferido a terceiros, nem usado para publicidade ou para treinar modelos de inteligência artificial. O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

5. Serviços utilizados

O aplicativo usa os Serviços de API do YouTube. Ao usá-lo, aplicam-se os Termos de Serviço do YouTube e a Política de Privacidade do Google.

6. Revogação e exclusão

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Ao revogar, os tokens deixam de funcionar; os arquivos locais podem ser apagados pelo autor a qualquer momento.

7. Contato

Dúvidas sobre esta política: github.com/Mystic0112.

Privacy Policy

Máquina de Shorts · last updated: October 3, 2026

1. What this app is

Máquina de Shorts is a personal automation tool. It is operated solely by its author, on the author's own computer, to publish videos to the author's own YouTube channel. It is not offered to third parties and no one else signs in to it.

2. Google data accessed

With the author's authorization through Google OAuth, the app accesses only the author's own YouTube account in order to:

  • upload videos and set each video's title, description, tags and privacy status;
  • read channel and video information and statistics (views, likes, subscribers and, when available, revenue), shown on a local dashboard.

3. Storage

Access tokens and retrieved data are stored only on the author's computer. There is no external server, cloud database or copy of this data outside that machine.

4. Sharing

No data is sold, shared or transferred to third parties, or used for advertising or to train artificial intelligence models. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Services used

This app uses YouTube API Services. By using it, the YouTube Terms of Service and the Google Privacy Policy apply.

6. Revocation and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Once revoked, tokens stop working; local files can be deleted by the author at any time.

7. Contact

Questions about this policy: github.com/Mystic0112.
