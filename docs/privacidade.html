Política de Privacidade

Máquina de Shorts · última atualização: 3 de outubro de 2026

1. O que é este aplicativo

A Máquina de Shorts é uma ferramenta pessoal de automação. Ela é operada exclusivamente pelo seu autor, no próprio computador, para publicar vídeos nas contas do próprio autor no YouTube, no Instagram e no TikTok. Ela não é oferecida a terceiros e nenhuma outra pessoa faz login nela.

2. Dados acessados

Com a autorização do autor, dada pelo login oficial de cada plataforma, o aplicativo acessa apenas as contas do próprio autor:

YouTube (Google)

  • enviar vídeos e definir título, descrição, tags e privacidade de cada vídeo;
  • ler informações e estatísticas do canal e dos vídeos (views, curtidas, inscritos e, quando disponível, receita), exibidas num painel local.

Instagram (Meta)

  • ler o ID, o nome de usuário e o tipo da conta profissional do autor;
  • publicar Reels com legenda nessa conta;
  • ler estatísticas dos Reels publicados (reproduções, alcance, curtidas, comentários e salvamentos), exibidas num painel local.

TikTok

  • ler as informações básicas do perfil do autor;
  • enviar vídeos para a conta do autor (como rascunho ou publicação);
  • ler estatísticas dos vídeos publicados (views, curtidas, comentários e compartilhamentos), exibidas num painel local.

3. Armazenamento

Os tokens de acesso e os dados lidos ficam armazenados somente no computador do autor. Não existe servidor externo, banco de dados na nuvem ou cópia desses dados fora dessa máquina. A página de retorno do login (oauth/callback.html, neste site) só repassa o código de autorização para o próprio computador do autor (127.0.0.1) e não o envia a nenhum servidor.

4. Compartilhamento

Nenhum dado é vendido, compartilhado ou transferido a terceiros, nem usado para publicidade ou para treinar modelos de inteligência artificial. O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. Os dados recebidos da Meta e do TikTok são usados apenas para as finalidades acima, conforme os Termos da Plataforma da Meta e os Termos para Desenvolvedores do TikTok.

5. Serviços utilizados

O aplicativo usa os Serviços de API do YouTube, a API do Instagram (Meta) e a API do TikTok. Ao usá-lo, aplicam-se os Termos de Serviço do YouTube, a Política de Privacidade do Google, a Política de Privacidade do Instagram e a Política de Privacidade do TikTok.

6. Revogação e exclusão

O acesso pode ser revogado a qualquer momento:

  • Google/YouTube: em myaccount.google.com/permissions;
  • Instagram: no app, em Configurações → Apps e sites → Ativos → Remover;
  • TikTok: no app, em Configurações e privacidade → Segurança → Apps e serviços → Remover acesso.

Ao revogar, os tokens deixam de funcionar. Para excluir os dados, o autor apaga os arquivos locais (tokens em secrets/ e estatísticas em data/) a qualquer momento; não há cópia em outro lugar.

7. Contato

Dúvidas sobre esta política: github.com/Mystic0112.

Privacy Policy

Máquina de Shorts · last updated: October 3, 2026

1. What this app is

Máquina de Shorts is a personal automation tool. It is operated solely by its author, on the author's own computer, to publish videos to the author's own YouTube, Instagram and TikTok accounts. It is not offered to third parties and no one else signs in to it.

2. Data accessed

With the author's authorization through each platform's official login, the app accesses only the author's own accounts in order to:

YouTube (Google)

  • upload videos and set each video's title, description, tags and privacy status;
  • read channel and video information and statistics (views, likes, subscribers and, when available, revenue), shown on a local dashboard.

Instagram (Meta)

  • read the author's professional account ID, username and account type;
  • publish Reels with captions to that account;
  • read statistics of the published Reels (plays, reach, likes, comments and saves), shown on a local dashboard.

TikTok

  • read the author's basic profile information;
  • upload videos to the author's account (as drafts or posts);
  • read statistics of the published videos (views, likes, comments and shares), shown on a local dashboard.

3. Storage

Access tokens and retrieved data are stored only on the author's computer. There is no external server, cloud database or copy of this data outside that machine. The login return page (oauth/callback.html, on this site) only hands the authorization code to the author's own computer (127.0.0.1) and never sends it to any server.

4. Sharing

No data is sold, shared or transferred to third parties, or used for advertising or to train artificial intelligence models. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data received from Meta and TikTok is used only for the purposes above, in accordance with the Meta Platform Terms and the TikTok Developer Terms of Service.

5. Services used

This app uses YouTube API Services, the Instagram API (Meta) and the TikTok API. By using it, the YouTube Terms of Service, the Google Privacy Policy, the Instagram Privacy Policy and the TikTok Privacy Policy apply.

6. Revocation and deletion

Access can be revoked at any time:

  • Google/YouTube: at myaccount.google.com/permissions;
  • Instagram: in the app, Settings → Apps and websites → Active → Remove;
  • TikTok: in the app, Settings and privacy → Security → Apps and services → Remove access.

Once revoked, tokens stop working. To delete the data, the author deletes the local files (tokens in secrets/ and statistics in data/) at any time; no copy exists anywhere else.

Questions about this policy: github.com/Mystic0112.
